# Windows Maintenance Toolkit

Windows 11向けの半自動メンテナンスツール。更新・検査・整理の入口を一つにまとめ、設定画面やアプリを探す手間を減らします。

## 検証状況

元版では一連の処理の終了、更新検索・WinGetの出力・Defenderのスキャン時刻を確認済みです。この公開版は表示文言や保存先の名称などを整理した派生版で、公開版そのものの再実行・構文検証は未実施です。すべてのPC構成や組織管理端末での動作は保証しません。

## 機能と限界

| 項目 | 動作 |
| --- | --- |
| Windows Update | 検索し、候補があれば承認後に一括適用。インストール時の再検索で対象が変わる可能性があります |
| 一般アプリ | winget upgrade --all。未認識・バージョン不明・固定されたアプリ等は網羅しません |
| Microsoft Defender | 定義更新とクイックスキャン。フルスキャンではありません |
| Edge / Chrome | 更新確認画面を開きます。確認終了を待ち、必要なら手動でブラウザーを再起動します |
| オプション更新 / Store | 対応画面を開きます。確認・適用は手動です |
| Dell SupportAssist | アプリを開きます。全体スキャンの開始と結果確認は手動です |
| PC Manager | アプリを開きます。ブースト・正常性チェック・詳細クリーンアップは手動です |

Enterによる続行は作業完了の証明ではありません。例外を表示した後も次の工程へ進むため、最後まで進んでも全件成功とは限りません。脅威と対処結果はWindowsセキュリティの保護の履歴で確認してください。

## 前提条件

- Windows 11 / Windows PowerShell 5.1、管理者権限、インターネット接続
- WinGet、動作中のMicrosoft Defender
- 対象のブラウザー・アプリがインストール済みであること。Dell SupportAssistは対応端末で使用してください
- PowerShell Gallery配布の第三者モジュール PSWindowsUpdate（元版で使用したバージョンは2.2.1.5）

必要な場合は管理者のWindows PowerShellで導入します。モジュールは同梱していません。配布元と内容を確認してください。

```powershell
Install-Module -Name PSWindowsUpdate -Repository PSGallery -Scope AllUsers
```

## 実行方法

1. Maintenance.ps1とStart-Maintenance.cmdを同じフォルダーに保存します。
2. スクリプトの内容を確認し、作業を保存します。
3. Start-Maintenance.cmdをダブルクリックし、管理者権限の確認を承認します。
4. 開始する場合だけYを入力します。Windows Updateの候補がある場合は別途適用確認があります。
5. 手動工程では各アプリで操作・結果確認後、PowerShellへ戻ってEnterを押します。

ダウンロード由来の署名エラーが出た場合は、内容を確認したうえで、このファイルだけブロック解除してください。組織のポリシーで禁止されている場合は回避せず管理者へ相談します。

```powershell
Unblock-File -LiteralPath '実際の保存先\Maintenance.ps1'
```

起動用ファイルは子プロセスにRemoteSignedを指定します。PC全体の実行ポリシーは変更しません。UnrestrictedやBypassへの恒久変更は不要です。

## 安全上の注意

- 管理者権限でソフトウェアを更新します。実行前に保存・必要なバックアップを行ってください。
- スクリプトからのアプリ強制終了、直接のファイル削除、Windowsの自動再起動は行いません。ただし更新対象アプリやインストーラー自身の挙動までは保証しません。
- オプション更新やドライバーをすべて自動適用する設計ではありません。内容を確認してください。
- PC Managerの削除対象・履歴消去・アプリ終了は利用者が判断してください。
- 標準的な場所にないブラウザーや名前の異なるアプリは検出できない場合があります。

## ログ

実行ログは利用者のPC内の `%LOCALAPPDATA%\WindowsMaintenance\Logs` に保存します。`%LOCALAPPDATA%`は実行ユーザーごとのアプリデータ保存先を示す環境変数です。特定の氏名やユーザー名はコードに固定していません。

ログには実行環境のユーザー名、パス、アプリ情報などが含まれる場合があります。実ログや未加工のスクリーンショットは公開しないでください。出力例は架空データで作成します。

.gitignoreはログ用フォルダーとprivate-outputを除外します。任意の場所へコピーした.txtログを一律に除外するものではありません。コミット前に差分を確認してください。
