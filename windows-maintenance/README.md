# Windows Maintenance Toolkit

Windows 11向けの半自動メンテナンスツール。毎回複数の設定画面やアプリを探す手間を減らし、更新・検査・整理の入口を一つにまとめます。

## 状態と検証範囲

検証環境で、日本語表示の元版が最後まで進むこと、更新検索・WinGetの出力・Defenderのスキャン時刻を確認しました。公開版は表示文言を英語に整理した派生版で、この公開版そのものの再実行・構文検証は未実施です。他のPCや組織管理端末での動作は保証しません。

## 機能と限界

| 項目 | 動作 |
| --- | --- |
| Windows Update | 検索し、候補があれば承認後に一括適用。インストール時は再検索するため、最初の一覧と対象が変わる可能性があります |
| 一般アプリ | winget upgrade --all。未認識・バージョン不明・固定されたアプリ等は網羅しません |
| Microsoft Defender | 定義更新とクイックスキャン。フルスキャンではありません |
| Edge / Chrome | 更新確認画面を開きます。確認終了を待ち、必要なら手動でブラウザーを再起動してください |
| オプション更新 / Store | 対応画面を開きます。確認・適用ボタンは手動です |
| Dell SupportAssist | アプリを開きます。全体スキャンの開始と結果確認は手動です |
| PC Manager | アプリを開きます。ブースト・正常性チェック・詳細クリーンアップは手動です |

Enterによる続行は作業完了の証明ではありません。例外を表示した後も次の工程へ進むため、最後まで進んでも全件成功とは限りません。脅威の有無はWindowsセキュリティの保護の履歴で確認してください。

## 前提条件

- Windows 11 / Windows PowerShell 5.1、管理者権限、インターネット接続
- WinGet、動作中のMicrosoft Defender
- Edge、Chrome、Microsoft Store。Dell SupportAssistとMicrosoft PC Managerは対象PCに別途導入済みであること
- PowerShell Gallery配布の第三者モジュール PSWindowsUpdate（元版で使用したバージョンは2.2.1.5）

管理者のWindows PowerShellで、必要なら次を実行します。モジュールは本リポジトリには同梱していません。配布元と内容を確認して導入してください。

```powershell
Install-Module -Name PSWindowsUpdate -Repository PSGallery -Scope AllUsers
```

## 実行方法

1. Maintenance.ps1とStart-Maintenance.cmdを同じフォルダーに保存します。
2. 必要に応じてスクリプトをエディターで確認し、作業を保存します。
3. Start-Maintenance.cmdをダブルクリックし、管理者権限の確認を承認します。
4. 開始する場合だけYを入力します。Windows Updateの候補がある場合は、別途適用確認があります。
5. 手動工程では各アプリで操作・結果確認後、PowerShellへ戻ってEnterを押します。

ダウンロード由来の署名エラーが出た場合は、コードの内容を確認したうえで、このファイルだけブロック解除してください。組織のポリシーで禁止されている場合は回避せず管理者へ相談します。

```powershell
Unblock-File -LiteralPath '実際の保存先\Maintenance.ps1'
```

起動用ファイルは子プロセスにRemoteSignedを指定します。PC全体の実行ポリシーは変更しません。UnrestrictedやBypassへの恒久変更は不要です。

## 安全上の注意

- 管理者権限でソフトウェアを更新するツールです。実行前に保存・必要なバックアップを行ってください。
- スクリプトからアプリを強制終了したり、直接ファイルを削除したり、Windowsを自動再起動したりする処理はありません。更新対象アプリやインストーラー自身の挙動まで保証するものではありません。
- オプション更新やドライバーをすべて自動適用する設計ではありません。内容を確認してください。
- PC Managerの削除対象・履歴消去・アプリ終了の提案は利用者が判断してください。
- 標準的な場所にないブラウザーや名前の異なるアプリは検出できない場合があります。

## ログと個人情報

ログはローカルの `%LOCALAPPDATA%\WindowsMaintenance\Logs` に保存します。ユーザー名、パス、アプリ情報などが含まれる場合があります。実ログや未加工のスクリーンショットはGitHubに登録しないでください。必要な出力例は架空データで作成します。

このフォルダーの.gitignoreはログ用フォルダーとprivate-outputを除外します。任意の場所にコピーした.txtログを一律に除外するものではありません。コミット前に必ず差分を確認してください。
