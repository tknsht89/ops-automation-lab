# Operations Automation Lab

Small Python tools and learning experiments for practical workflow automation.

## Purpose

This repository documents small, practical automation experiments that reduce repetitive operational work and improve reliability.

The focus is on understandable scripts, clear inputs and outputs, and improvements that can be maintained over time.

## Topics

- CSV cleanup and data normalization
- File naming and file organization
- Small Python scripts for repetitive tasks
- Quote comparison and operational data preparation
- Code experiments, failures, fixes, and lessons learned

## Working Principles

- Start with a small working example
- Use fictional, anonymized, sanitized, or modified data
- Record the input, output, and intended use of each tool
- Document failures, causes, fixes, and lessons learned
- Prefer clear and maintainable code over unnecessary complexity
