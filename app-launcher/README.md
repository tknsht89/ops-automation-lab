# App Launcher

Windowsで、チェックしたアプリだけをまとめて起動するPowerShell製のデスクトップツールです。Windowsアプリ18項目と、ChromeにインストールしたWebアプリ9項目を登録しています。

## 機能

- チェック式の起動対象選択
- WindowsアプリとChrome Webアプリの起動
- 起動要求・エラーの画面内表示
- 起動処理後のチェック解除

## 動作環境

- Windowsの対話型デスクトップ環境
- Windows PowerShell 5.1、Windows Forms、Get-StartApps
- 対象アプリの事前インストール
- WebアプリにはGoogle Chromeと対応するインストール済みWebアプリが必要

## 使い方

1. このフォルダー内のファイルを同じ場所に保存します。
2. Start-Launcher.cmdをダブルクリックします。
3. 起動対象にチェックを入れ、「選択したアプリを起動」を押します。

最初は1つずつ確認してください。管理者実行は想定していません。セキュリティ警告や組織の制限は無理に解除しないでください。

## 環境に合わせた変更

AppLauncher.ps1の$appsで起動対象を管理します。Windows側はGet-StartAppsに表示される名前と一致させてください。Chrome側は各環境のWebアプリIDとプロフィール指定に合わせて変更してください。初期設定はDefaultプロフィールです。Chromeのインストール先が異なる場合は$proxyも変更してください。

## 制限と注意

- 元の起動処理では登録27項目を単一のWindows環境で確認しています。公開用に整理した本版の起動用CMDを含む再テストは未実施です。他の環境での動作を保証しません。
- 全項目未選択で開きます。起動ボタンを押すまで対象アプリを起動しません。
- 起動要求の送信は正常起動・ログイン完了を保証しません。
- 起動中アプリの重複起動防止、選択内容の保存、画面内ログのファイル保存は未実装です。
- ランチャーは自動起動登録、Git操作、録音・録画開始操作を行いません。各アプリ自身は既存設定に従って動作します。
- 起動用CMDはそのPowerShellプロセスにExecutionPolicy Bypassを指定します。永続的な実行ポリシー変更は行いません。
- アプリ本体、認証情報、ブラウザーのプロフィールデータは同梱していません。
